# Nixvim Dendritic Rewrite

## Rules
- Do not rewrite any working file wholesale — make only the changes listed
- Plugin keymaps stay with their plugin file
- `builtins.fetchGit` is impure — run all checks with `--impure`; do not change it
- `perSystem` belongs in profile modules, not in `flake.nix`
- `systems` stays in `flake.nix` under `config.systems` (required when `options` is declared at top level)

---

## 1. flake.nix — targeted changes only

**a. Add `import-tree` to inputs:**
```nix
import-tree.url = "github:vic/import-tree";
```

**b. Replace the body with a function and strip `perSystem`:**
```nix
outputs = { nixvim, flake-parts, ... }@inputs:
  flake-parts.lib.mkFlake { inherit inputs; } (
    { lib, ... }:
    {
      imports = [
        (inputs.import-tree ./modules)
        (inputs.import-tree ./profiles)
      ];

      options.flake.modules.nixvim = lib.mkOption {
        type    = lib.types.lazyAttrsOf lib.types.deferredModule;
        default = {};
      };

      config.systems = [
        "x86_64-linux"
        "aarch64-linux"
        "x86_64-darwin"
        "aarch64-darwin"
      ];
    }
  );
```

The `perSystem`, `pkgs'`, `nixvimModule`, `nvim` definitions are removed from `flake.nix` entirely — they move into `modules/profiles/full.nix` and `modules/profiles/light.nix`.

## 3. Module file pattern

Every aspect file is a flake-parts module that sets one key in `config.flake.modules.nixvim`:

```nix
{ config, lib, inputs, ... }: {
  config.flake.modules.nixvim.<name> = { pkgs, ... }: {
    # nixvim module content
  };
}
```

Profile files set `perSystem` and read `config.flake.modules.nixvim`:

```nix
{ config, inputs, ... }: {
  perSystem = { pkgs, system, ... }: let
    mods    = config.flake.modules.nixvim;
    nixvimLib = inputs.nixvim.lib.${system};
    nixvim'   = inputs.nixvim.legacyPackages.${system};
    pkgs' = pkgs.extend (final: prev: {
      vimPlugins = prev.vimPlugins.extend (vfinal: vprev: {
        obsidian-nvim = vprev.obsidian-nvim.overrideAttrs (_: { doCheck = false; });
      });
    });
    nixvimModule = {
      pkgs   = pkgs';
      module = { imports = with mods; [ ... ]; };
      extraSpecialArgs = { pkgs = pkgs'; };
    };
    nvim = nixvim'.makeNixvimWithModule nixvimModule;
  in {
    packages.<name> = nvim;
    checks.<name>   = nixvimLib.check.mkTestDerivationFromNixvimModule nixvimModule;
  };
}
```

## 6. autoCmd callback fix

In `modules/base.nix`, both autoCmd `__raw` callbacks use `function _()`. This is invalid Lua as an expression (named function definitions are statements, not values). Stylua rejects it during `nix flake check`. Change both to `function()`:

```nix
# remove trailing whitespace
callback = { __raw = ''function()
      ...
  end''; };

# highlight yank
callback = { __raw = ''function()
      ...
  end''; };
```

This bug was pre-existing in `config/default.nix` but was never caught because `nix build .` does not run the check derivation.

## 8. Fix otter miss-name diagnostic

`modules/ide.nix` already disables `"missing-name"` in lua_ls settings. The otter diagnostic is `[miss-name]` — a different ID. Add it to the disable list:

```nix
lua_ls = {
  settings.diagnostics.disable = [ "missing-name" "miss-name" ];
};
```
